# Modelo Whisper embutido no instalador

A [ADR-0004](./0004-transcricao-offline-com-whisper.md) deixou o modelo ggml fora do instalador: a terapeuta baixaria o arquivo uma vez para `modelos/`, ao lado do `ebers.db`. Na primeira instalação real isso falhou do jeito previsível — o botão do microfone avisou "Modelo de transcrição não instalado", e o passo (488 MB, num arquivo de nome exato, numa pasta oculta dentro de `~/Library`) pareceu uma biblioteca faltando. É um passo técnico sobrando para quem não deve ter nenhum. Decidimos **embutir o `ggml-small.bin` no próprio app**: a task `mise run modelo` baixa o arquivo uma vez para `src-tauri/recursos/modelos/` (fora do git, SHA-256 conferido) e o `bundle.resources` do Tauri o copia para `Contents/Resources/modelos/` do bundle. O backend procura o modelo primeiro em `modelos/` da pasta de dados e depois no bundle: um arquivo na pasta de dados, quando existe, sobrepõe o embutido — o que preserva a exceção para a máquina que não acompanha o `small` (o desenvolvedor põe um `base` ali). Redistribuir é permitido: os pesos do Whisper (OpenAI) e as conversões ggml (whisper.cpp) são MIT, cuja condição é levar o aviso de copyright junto — o script deixa um `LICENSE.txt` ao lado do modelo, que entra no bundle pelo mesmo caminho.

## Alternativas

- **Download automático na primeira abertura**: mantém o instalador em 13 MB, mas põe cliente HTTP, barra de progresso, verificação, retomada e uma URL estável no caminho crítico — e cria um aviso novo para a terapeuta ver ("sem internet, não consigo baixar"). O consultório não deve depender de rede para o app funcionar, como a ADR-0004 já dizia.
- **Download durante a instalação**: não existe no macOS — instalar é arrastar o app do DMG. Um `.pkg` com script pós-instalação rodaria como root, sem saber em qual `~/Library` deixar o arquivo.

## Consequências

- O DMG passa de 13 MB para 460 MB (o `.app`, de 33 MB para 520 MB). O argumento da ADR-0004 (todo update pagaria pelo binário que nunca muda) perde força: atualização é o desenvolvedor levando um DMG para uma única máquina.
- `cargo test` e `tauri dev` continuam funcionando sem o modelo: o `build.rs` garante a pasta `recursos/modelos`, que o tauri-build ignora quando vazia (e aborta quando ausente). Em `dev` sem o arquivo ali, vale só a pasta de dados, como antes.
- O aviso "Modelo de transcrição não instalado — veja o guia de operação" vira "Modelo de transcrição não encontrado — a instalação precisa ser refeita": sem o modelo embutido, a instalação está avariada. O guia de operação deixa de ensinar o download; a exceção de `modelos/` passa a ser documentação do desenvolvedor (README).
- Um modelo na pasta de dados que existe mas não carrega (download interrompido, por exemplo) não esconde o embutido: a transcrição tenta os candidatos na ordem de precedência e fica com o primeiro que carregar; o que falhou é lembrado e não é reaberto até o app reabrir (o whisper.cpp não libera o que alocou numa carga que falha). O caminho completo do modelo em uso vai para o stderr — o nome do arquivo é o mesmo nos dois lugares.
- Só o `small` vai embutido. É o melhor dos três que a ADR-0004 aceita e erra menos da metade das palavras do `base` — WER de 7,4% contra 19,6% no banco de referência em pt-BR clínico do #14 (commit 937a1e9); ainda assim transcreve mais rápido do que se fala num Mac de 2019 (3,7× o tempo real num i7-9750H, [ADR-0006](./0006-build-de-distribuicao-do-whisper.md)). `base` e `tiny` continuam aceitos pela pasta de dados.
